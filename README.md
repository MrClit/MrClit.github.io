## 🚀 Technologies Used

- ⚡ **React 19** + **TypeScript** (strict) on **Vite 8** for blazing-fast development
- 🎨 **Tailwind CSS 4** for modern, responsive styling
- 🔄 **React Router 7** for seamless navigation
- 🏪 **Zustand 5** for elegant state management
- 🌍 **i18next** for internationalization (English, Spanish, Catalan)
- 🎬 **Framer Motion** for animations
- ✨ **React Icons** for iconography

## 🛠️ Getting Started

> **Requirements:** Node.js ≥ 24 and [pnpm](https://pnpm.io) as the package manager.

1. **Clone the repository**
2. **Install dependencies:**
   ```bash
   pnpm install
   ```
3. **Start the development server:**
   ```bash
   pnpm dev
   ```
4. **Open** [`http://localhost:5173`](http://localhost:5173) **in your browser**

Other useful commands:

```bash
pnpm build     # production build → dist/
pnpm preview   # preview the production build
```

## 🏗️ Project Structure

- `src/pages` – Main website sections (Home, Projects, About)
- `src/components` – Reusable UI components
- `src/store` – Global state management with Zustand
- `src/data` – Portfolio project data
- `src/i18n` – Translations (English, Spanish, Catalan)
- `public` – Static assets (images, favicon)
